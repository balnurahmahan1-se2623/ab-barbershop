### How to run the project locally (Fallback Deployment)
1. Install and open XAMPP on your computer.
2. Start the Apache server in the XAMPP Control Panel.
3. Place our project folder into the `htdocs` directory inside XAMPP.
4. Open your web browser and go to: `http://localhost/ab-barbershop`
5. The SQLite database (`barbershop.db`) is already included in the project folder.
